# Owner design requirements

- Preserve existing public-site typography when applying visual references. Reuse the current Manrope heading/body font, Georgia italic emphasis, and established responsive type sizes, weights, line heights and tracking. Do not copy typography from screenshots or introduce new type scales unless explicitly requested.
- Olive remains the primary color.
- References provide layout ideas only. Keep the site's own light/dark surface, border, text and Olive color tokens. Do not copy hardcoded reference palettes, dark cards in light mode, or decorative gradients. Hero rating cards use `--card`, `--line`, `--ink`, `--muted` and `--action`.
- Implement only the page/section the owner selects. Convert a selected legacy page to Next.js/React before redesigning it, and show the conversion before subsequent design changes when requested.
- Reviews: the agency has two Fiverr profiles and a five-member team. Do not describe the two profiles as two team members.
